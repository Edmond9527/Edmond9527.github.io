基于大语言模型的文本智能分析与报告助手

队长 · 系统总体设计

2026.01 – 2026.03

AMD 赛道三等奖, 多校联合电子设计与创新“寒假大作战”

[代码与报告]

研究概述

在 AMD GPU 远程 JupyterHub 环境中，基于 qwen3-coder:30b 开发文本分析系统，支持文档摘要、关键词提取与多文档对比，并输出 Markdown 报告。

主要功能

  • 摘要生成：提炼文档的主要内容。
  • 关键词提取：识别关键主题，辅助内容整理。
  • 多文档对比：比较不同文档，并将分析整理为报告。

处理流程结合批量文件解析、模型 API 调用与并发处理，配合提示词设计和上下文管理完成分析任务。

个人贡献

作为队长，我负责系统总体设计，设计提示词与上下文管理流程，衔接文档解析、模型调用和报告生成。

项目成果

项目获得 2026 年多校联合电子设计与创新“寒假大作战”AMD 赛道三等奖。代码与报告已整理到 GitHub 仓库。
