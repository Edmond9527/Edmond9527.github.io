项目概述

面向多文档阅读与信息整理，开发基于大语言模型的文本智能分析系统，实现摘要、关键词提取与多文档对比，并以 Markdown 格式输出报告。

系统运行于 AMD GPU 远程 JupyterHub 环境，使用 qwen3-coder:30b，结合提示词设计和上下文管理流程完成分析任务。

主要功能

01

摘要生成

从文本中提炼主要内容，帮助快速了解文档。

02

关键词提取

提取关键主题，辅助文本内容整理。

03

多文档对比

对多份文档进行比较，并组织为 Markdown 报告。

实现环节包括批量文件解析、模型 API 调用和并发处理，配合上下文管理组织多文档分析。

个人贡献

担任队长，负责系统总体设计，设计提示词与上下文管理流程，将文本解析、模型调用及报告输出衔接起来。

项目成果

获得 2026 年多校联合电子设计与创新“寒假大作战”AMD 赛道三等奖。项目代码和报告已整理至 GitHub 仓库。

运行环境：AMD GPU / JupyterHub
模型：qwen3-coder:30b
报告格式：Markdown
