LLM-Based Text Analysis and Reporting Assistant

Team Leader · Overall System Design

January – March 2026

Third Prize, AMD Track, Inter-University Winter Innovation Challenge

[Code & Report]

Overview

A text analysis system built with qwen3-coder:30b in an AMD GPU remote JupyterHub environment. It supports document summarization, keyword extraction, and multi-document comparison, producing reports in Markdown.

Features

  • Summarization: extracts the main content of a document.
  • Keyword extraction: identifies key topics for content organization.
  • Multi-document comparison: compares documents and organizes the analysis into a report.

The processing workflow combines batch file parsing, model API calls, concurrent processing, prompt design, and context management.

My Contribution

As team leader, I was responsible for the overall system design, including the prompt and context-management workflow connecting document parsing, model calls, and report generation.

Outcome

The project received Third Prize in the AMD Track of the 2026 Inter-University Winter Innovation Challenge. Code and reports are available in the linked GitHub repository.
