# 李丰毅 · 个人主页

面向保研与科研申请的个人网站，关注计算机视觉、通用模型与多模态大模型，包含当前研究、论文与项目、教育经历、荣誉及简历下载。使用 HTML、CSS 和 JavaScript，可直接部署至 GitHub Pages。

## 发布到 GitHub Pages

1. 登录 GitHub 账号 `Edmond9527`，创建公开仓库 `Edmond9527.github.io`。如果该仓库已有内容，先保留原文件，再更新网站文件。
2. 将本目录中的 `index.html`、`assets/`、`projects/` 和 `.nojekyll` 放入仓库根目录。首页文件应直接位于根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/ (root)**，保存。
5. 部署完成后访问 `https://edmond9527.github.io/`。该地址可附在简历中。

官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 本地预览

直接打开 `index.html` 即可浏览。使用本地静态文件服务器时，将服务目录设为本目录。

## 更新内容

- `index.html`：首页文字、研究项目入口、教育背景、奖项和联系方式。
- `projects/wavemamba.html`：WaveMamba 论文详情。
- `projects/deaffnet.html`：DEAFFNet 论文详情。
- `projects/report-assistant.html`：文本分析与报告助手详情。
- `assets/style.css`：配色、排版和移动端适配。
- `assets/main.js`：移动导航、章节指示和页脚年份。
- `assets/cv.pdf`：供访问者预览与下载的简历。更新时使用相同文件名替换。

创新训练项目的“进行中”状态需在项目结束后更新。学业排名标注了对应学年，更新排名时同时修改学年。
